About the model

This calculator uses a pre-shot expected goals model trained on 42,258 shots from 1,696 matches across multiple competitions.

The pitch shows only the attacking half. The yellow area represents the visible goal angle from the selected shooting position.

The model considers shot location, distance, angle, body part, chance origin and contextual information such as pressure, first-time attempts, one-on-one situations and open goals.
